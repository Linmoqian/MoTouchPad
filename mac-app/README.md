# MoTouchPad for macOS

接收 iOS / Android 原始触控快照，通过 CGEvent 控制桌面。最低支持 macOS 13。

## 构建与运行

    cd mac-app
    swift build
    swift test
    swift run MoTouchPadMac

在系统设置 → 隐私与安全性 → 辅助功能中授权 MoTouchPad，以允许鼠标和快捷键注入。

## 手势

| 触点 | 动作 | 桌面行为 |
|---|---|---|
| 单指 | 移动、轻点、连续两次轻点 | 相对指针、左键和系统双击 |
| 单指 | 轻点后再次按住并移动 | 左键拖移，抬起结束 |
| 双指 | 轻点、纵向移动、慢速横移、快速横扫 | 右键、滚动、水平滚动、前进/后退 |
| 双指 | 捏合、旋转、连续两次轻点 | 放大/缩小、旋转、智能缩放快捷键 |
| 三指 | 轻点、快速上滑、停留或移动 | 查词、App Exposé、持续左键拖移 |
| 四指 | 轻点、上下左右快滑 | 切换应用、调度中心、App Exposé、空间切换 |
| 四指 | 整体张开/合拢 | 显示桌面、应用启动器 |

双指捏合、旋转和平移按首次跨阈值锁定。快速三指上滑打开 App Exposé；静止三指
停留 0.12 秒可拖移，无需手机重复发送静止帧。五指、取消、触点 ID 变化和断连
清理手势；拖移始终释放左键。多指轻点支持触点逐个 UP，无 UP 的空帧不会点击。

## 手势设置

窗口的“手势设置”提供一套全局快捷键映射，存储在本机 UserDefaults。可录制、
清除单项和恢复默认值。快捷键发送给当前前台 App，没有按 App 独立档案。

默认包括 Command+[ / ]、Command+= / -、Control+Command+D、Control+箭头、
Fn+F11、Fn+Shift+A，以及四指轻点的 Command+Tab。旋转和智能缩放默认未配置。
未绑定命令静默，系统或 App 改写快捷键后可同步修改这里的绑定。

默认双指右键在 UP 时立即触发。配置智能缩放后，右键等待 0.30 秒以区分双指双击。
较新 macOS 可能将“启动台”呈现为“Apps”，应用启动器的绑定同样可修改。
CGEvent 发送鼠标、滚轮和组合键；应用对快捷键的支持决定缩放与旋转是否生效。

## 低延迟路径

- TCP protocol v1 / 47651，noDelay 关闭小包聚合等待，每秒一个 0x7F 心跳。
- 流式解码按原缓冲偏移批量读取，只保留末尾残帧，支持分片与合包。
- 每批只派发一次主线程回调，回调消费前再次检查连接代际，拒绝旧连接帧。
- 输入逐帧处理；接收状态显示最多每秒更新 10 次。
- 触点 ID 使用 256 位固定掩码，几何计算减少临时数组和 Set 分配。
- 单指移动阈值 0.004；首次指针、滚动、捏合输出保留分类前积累量。

## 基准与测试

运行 Release 微基准（5 次中位数，不注入真实输入）：

    swift run -c release TouchPipelineBenchmark

基准测量本机 CPU 的解码、识别与批量解析耗时；不同设备的单调时钟不能直接相减，
这些数字不等同于手机到桌面的 Wi-Fi 单向延迟。真实网络延迟需通过设备上的端到端
测量确认。swift test 覆盖协议、手势、输入执行器、偏好持久化以及本机真实 TCP 回环。

mac-driver/ 是独立 DriverKit 实验占位，不进入应用路由。
